🏛️ Aksara Kaganga — Warisan Leluhur Rejang

Aksara tradisional masyarakat Rejang, Bengkulu. Termasuk kelompok aksara Abugida — setiap konsonan mengandung bunyi vokal 'a' bawaan. Terdaftar dalam Unicode blok U+A930–U+A95F (2009).

🔤 Konsonan (23 huruf)
🔵 Tanda Vokal (Diakritik)

Vokal selain 'a' dituliskan sebagai tanda di atas/bawah konsonan. Vokal 'a' adalah vokal bawaan.

🔢 Angka Rejang
📌 Aturan Penulisan
Arah
Ditulis dari kiri ke kanan, seperti tulisan Latin.
Vokal 'a'
Sudah terkandung dalam setiap konsonan. "Ka" = ꤰ
Vokal lain
Ditambahkan sebagai diakritik. "Ki" = ꤰꥇ (Ka + tanda I)
Konsonan mati
Ditandai virama ꥍ. "pak" = ꤶꤰꥍ
Font
"Noto Sans Rejang" (Google Fonts) untuk tampilan terbaik.

🌿 Tentang Proyek

Kamus Bahasa Rejang & Aksara Kaganga adalah proyek open source untuk melestarikan Bahasa Rejang — bahasa daerah Bengkulu yang kaya. Tersedia dalam 250+ kata, 5 dialek, dan 3 bahasa (Indonesia, Inggris, Rejang).

📥 Import Data BERENDO ke Kamus Ini

BERENDO menggunakan teknologi JavaScript dinamis sehingga tidak bisa diunduh otomatis. Ikuti langkah berikut untuk mengekstrak dan mengimpor datanya:

1
Buka berendo.kemendikdasmen.go.id/pencarian di browser.
2
Tekan F12 → pilih tab Console.
3
Salin kode di bawah ini dan tempel ke Console, lalu tekan Enter. File JSON akan terunduh otomatis.
4
Klik tombol "Import JSON BERENDO" di bawah dan pilih file yang baru diunduh.
